# 合成示例资料

此处保存从原 examples 目录移入的五份原始演示文件：finance.md、overseas.md、refund.md、sensor.md、sensor.pdf。文件内容未改写，原路径不再保留副本。

它们是合成的产品示例，不是用户生产资料，不是权威业务规则，也没有继承旧检索结果、片段 ID、质量指标或通过结论。未来可据可读原文人工选择最小测试小样；不得把它们当成完整企业评测集。

新增真实格式测试件需说明来源、用途与预期；不得混入密钥、个人敏感资料或未经授权的用户文档。当前M1的可执行示例见 ../../examples/quickstart.py，验证入口见 ../../README.md。

`processing-parameters.txt`为新增合成长文验收样本，150条重复句用于比较块长、重叠及标题索引，不是业务规则。页面复测步骤见[Python SDK 参数手册](../../docs/python-sdk.md)。
