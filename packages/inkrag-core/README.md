# InkRAG Core

Parse or import document evidence, index raw chunks with BM25 terms and embeddings, and retrieve it through selectable keyword, vector, reference-graph and multi-step routes. The base package uses the Python standard library.

See the [configuration and API guide](https://github.com/chenyk2016/inkrag/blob/main/docs/core-guide.md) and the [interactive maintainer guide](https://chenyk2016.github.io/inkrag/). Install the matching packages from GitHub Releases when using the optional InkParse adapter.
