# InkRAG Core

Parse or import document evidence, index raw chunks with BM25 terms and embeddings, and retrieve it through selectable keyword, vector, reference-graph and multi-step routes. The base package uses the Python standard library.

See the [project usage manual](https://github.com/chenyk2016/inkrag/blob/main/docs/core-guide.md) for configuration and API examples. Install the matching packages from GitHub Releases when using the optional InkParse adapter.
